# Unramble

Local-first interview practice partner. Built for the DEV Hacktoberfest Weekend challenge (October 2026): open-source AI at its core, built for one real friend.

## Stack

- Next.js (App Router) + TypeScript + Tailwind CSS v4
- Ollama (Gemma 3 4B) via REST for question generation and rubric scoring
- transformers.js (Whisper) for local speech-to-text

## Design direction

Read `design.md` (Notion design system) before any UI work. Purple #5645d4 is reserved for the one primary action per screen. Buttons are 8px rectangles, cards 12px, pills only for tabs/badges. Light-only theme.
