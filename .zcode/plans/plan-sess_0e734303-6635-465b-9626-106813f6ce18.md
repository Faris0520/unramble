# Unramble — a 100% local interview practice partner

## Product (locked from grilling)
A web app built for **one real friend** who is preparing for job interviews and whose problem is **rambling, unstructured answers**. It runs **fully offline on her laptop**: record your voice → transcribe locally → analyze against a rubric locally → structured feedback. No data ever leaves the laptop — that is the heart of the "why open innovation matters" story.

- **Stack:** Next.js (App Router) + Tailwind (TypeScript), Ollama REST + **Gemma 3 4B** (enters the Gemma partner category, $200), local transcription via transformers.js (Whisper) in an API route.
- **MVP = core loop only:** setup → voice practice → feedback. No TTS, no cross-session history.
- Name **Unramble** is used consistently across repo, UI, and the DEV post.

## MVP features
1. **/setup** — paste the job description + CV bullets (stored locally), pick the language; Gemma generates 6–8 personalized interview questions (JSON).
2. **/session** — one question per screen; answer via mic (MediaRecorder) → `/api/transcribe` (local Whisper) → transcript shown; re-answer or continue.
3. **/feedback** (the demo hero) — per question: **color-coded transcript** (Situation / Task / Action / Result / filler), rubric scores (STAR coverage, relevance, conciseness), a **restructured model answer**, an overall "rambling meter", and a re-drill button for the weakest question.
4. **Handover:** a two-command README + a `.bat` launcher for the friend's Windows laptop; no accounts, no server.
